# key-wayback

Робочий інструмент сектору електронної бібліотеки Національної бібліотеки України для дітей: знімки публічних сторінок порталу [КЛЮЧ](https://key.chl.kiev.ua) у Wayback Machine (Internet Archive) для контролю стану сайту в період відключень електроенергії.

## Як працює

Кожні 4 години GitHub Actions перевіряє доступність сайту й надсилає порцію сторінок у Save Page Now. Сторінки з `priority-urls.txt` перезнімаються щодня, решта сайту — по колу раз на 30 днів.

Зберігаються лише публічні сторінки. Адміністративна частина, особисті кабінети й API не архівуються.

## Журнали

- `archive-log/captures.csv` — що й коли збережено, з посиланнями на знімки
- `archive-log/availability.csv` — доступність сайту на момент кожної перевірки
